## 4. My Understanding

### Task 1.1 — IPOS for typing and saving a file

| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | I press keys and the keyboard sends each keypress to the computer as an electrical signal. | Keyboard |
| Processing | The CPU works out which character each key stands for, the editor program adds it to the text, and the text is held in memory while I work on it. | CPU, RAM |
| Output | The characters appear on the screen as I type. | Display |
| Storage | When I press save, the text is written to a file on the drive so it stays after the computer is switched off. | SSD |

The activity starts with my keypresses (input). The CPU and memory process them into text, the display shows the result (output), and saving copies the text from memory to the SSD (storage). Memory loses its contents when the power goes off, so storage is what keeps the file.

### Task 1.3 — Computer systems around me

| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Lets people withdraw cash and check balances | Card and PIN | Cash and a printed receipt |
| Smart TV | Plays video and apps | Remote control button press | Picture and sound |
| Traffic signal | Controls the flow of vehicles at a junction | Timer or vehicle sensor | Red, yellow or green light |

Each of these systems follows the same input, processing, output and storage pattern as a laptop. An ATM, for example, takes the card (input), checks the account (processing), gives cash (output) and records the transaction (storage).
